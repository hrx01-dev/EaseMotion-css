# Floating Input Field

Issue #78589 demonstrates a SaaS-style floating label input pattern.

## Features

- Floating labels
- Clear focus states
- Responsive layout
- Accessible native controls
- Reduced-motion support
- Pure HTML and vanilla CSS

## Usage

Open `demo.html` and reuse the `.field` pattern for forms where labels should remain visible after values are entered.

## Accessibility

Native inputs remain semantic and keyboard accessible. Focus indicators are preserved, and transition effects can be disabled with `prefers-reduced-motion`.
