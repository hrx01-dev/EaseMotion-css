# CSS Neumorphic Soft Shadow Progress

Issue #73502 demonstrates a soft neumorphic progress bar built entirely with CSS.

## Features

- Raised and inset neumorphic shadows
- Animated progress entrance
- Accessible progressbar semantics
- Responsive card layout
- Reduced-motion support
- No JavaScript or external assets

## Usage

Open `demo.html`. Change the `--value` custom property to adjust the progress amount.

## Files

- `demo.html` — semantic progress markup
- `style.css` — neumorphic styling and animation
- `README.md` — documentation
