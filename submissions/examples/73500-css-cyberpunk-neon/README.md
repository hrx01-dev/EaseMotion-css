# CSS Cyberpunk Neon Progress

Issue #73500 is a pure CSS progress bar with a high-contrast cyberpunk neon treatment.

## Features

- Neon gradient fill
- Animated charging entrance
- Accessible progressbar semantics
- Responsive sizing
- Dark-mode compatible
- Reduced-motion support
- No JavaScript or external assets

## Usage

Open `demo.html`. The progress value is controlled by the `--value` custom property.

## Files

- `demo.html` — semantic progress example
- `style.css` — neon visuals, animation, and responsive behavior
- `README.md` — implementation notes
