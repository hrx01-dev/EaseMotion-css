# Responsive Pastel Button

Issue #78595 demonstrates a friendly responsive button treatment using soft pastel surfaces.

## Features

- Responsive button layout
- Pastel visual states
- Hover and focus feedback
- Touch-friendly sizing
- Reduced-motion support
- Pure HTML and vanilla CSS

## Usage

Open `demo.html` and reuse the button classes for primary, secondary, and quiet actions.

## Accessibility

Native buttons remain keyboard accessible and receive a visible focus outline. Reduced-motion preferences remove transition effects.

- `demo.html` — expanded example
- `style.css` — component styling
