# CSS Metallic Sheen Text

## Overview

Issue #73413 demonstrates a smooth metallic sheen text animation using only HTML and vanilla CSS.

## Features

- Animated metallic highlight
- Dark-mode friendly palette
- Responsive typography
- Hardware-friendly CSS transforms and gradients
- Reduced-motion support
- No JavaScript or external dependencies

## Usage

Open `demo.html` in a modern browser. The heading automatically animates through a moving highlight.

## Accessibility

The animated effect is decorative and the text remains normal document content. Users who prefer reduced motion receive a static version of the treatment.

## Files

- `demo.html` — semantic demonstration markup
- `style.css` — layout, gradient treatment, animation, responsive rules, and accessibility behavior
- `README.md` — implementation notes
