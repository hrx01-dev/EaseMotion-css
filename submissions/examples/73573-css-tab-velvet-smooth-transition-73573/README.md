# CSS Tab: Velvet Smooth Transition

Issue #73573 demonstrates a soft segmented control with smooth transitions and a dark-mode-friendly surface.

## Requirements covered

- Pure HTML and vanilla CSS
- Smooth CSS transitions
- Responsive tabs layout
- Keyboard-accessible native links
- Dark interface compatibility
- Reduced-motion fallback

The active surface uses gradients and shadow depth to create the velvet-inspired appearance. No JavaScript is required for the interaction shown in the demo.

## Files

- `demo.html` — tab and segmented-control demonstration
- `style.css` — surface styling, transitions, and responsive rules
- `README.md` — documentation
