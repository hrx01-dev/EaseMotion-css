# CSS Minimalist Outline Progress

Issue #73516 provides a restrained outlined progress bar with a simple fill animation.

## Features

- Minimal visual language
- Clean outline track
- Smooth fill entrance
- Accessible progressbar semantics
- Responsive sizing
- Reduced-motion support
- No JavaScript

## Usage

Open `demo.html` and change the `--value` custom property to set the progress amount.

## Files

- `demo.html` — semantic progress example
- `style.css` — minimalist styling and animation
- `README.md` — documentation
