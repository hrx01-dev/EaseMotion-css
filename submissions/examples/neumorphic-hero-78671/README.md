# Neumorphic Hero — Issue #78671

A soft-surface hero showcase using layered shadows and responsive spacing.

## Files

- `demo.html` — semantic hero content and CTA.
- `style.css` — neumorphic surface treatment and responsive layout.

## Usage

Include the stylesheet and place the `.hero` section in your page. Update the content and CTA destination as needed.

## Accessibility

The heading is explicitly associated with the section, and the CTA remains a native keyboard-accessible link.
