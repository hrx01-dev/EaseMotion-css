# CSS Button: Origami Paper Fold

Issue #73254 demonstrates a paper-inspired button with a folded corner created using CSS pseudo-elements.

## Requirements covered

- Pure HTML and vanilla CSS
- Smooth transitions
- Responsive layout
- Dark-mode-friendly structure through neutral variables
- Hardware-friendly transform animation
- Native accessible buttons
- Reduced-motion fallback

The fold is decorative and does not affect button dimensions or document flow. Focus and hover reveal the same visual treatment.

## Files

- `demo.html` — button examples and implementation notes
- `style.css` — fold geometry, interaction, and responsive rules
- `README.md` — documentation
