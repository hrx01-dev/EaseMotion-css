# CSS Minimalist Outline Text

## Overview

Issue #73410 presents a minimal outlined text treatment using native CSS text stroke and transitions.

## Features

- Lightweight outlined typography
- Smooth hover and focus transition
- Dark-mode compatible presentation
- Responsive sizing
- Reduced-motion support
- Pure HTML and vanilla CSS

## Usage

Open `demo.html` in a modern browser and hover or focus the heading to reveal the filled state.

## Accessibility

The heading is normal HTML text and remains readable without animation. Focus styling is available for keyboard interaction, while reduced-motion preferences disable the transition.

## Files

- `demo.html` — semantic example markup
- `style.css` — outline effect and responsive behavior
- `README.md` — documentation
