# Parallax SaaS Footer

Issue #79687 demonstrates a responsive footer with layered depth and SaaS styling.

## Features

- Responsive footer columns
- Layered visual depth
- Keyboard-visible links
- Small-screen stacking
- Pure HTML and vanilla CSS

## Usage

Open demo.html to preview the component and link style.css when integrating it into another page.

## Responsive behavior

Footer columns collapse into a single readable stack on smaller screens.

## Accessibility

Navigation uses native links and visible keyboard focus.
