# Neumorphic Gradient Carousel

## Overview

Issue #78578 demonstrates a responsive carousel using soft neumorphic depth and gradient surfaces.

## Features

- Responsive card layout
- Raised and inset depth
- Gradient surfaces
- Accessible native controls
- Reduced-motion support
- Pure HTML and vanilla CSS

## Usage

Open `demo.html` in a modern browser. The example is self-contained and can be reused as a visual component reference.

## Files

- `demo.html` — semantic component demonstration
- `style.css` — responsive visual system
- `README.md` — implementation notes
