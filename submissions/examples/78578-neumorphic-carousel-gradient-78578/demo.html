IMPLEMENTATION

Design notes

Depth

Paired shadows establish raised and inset states without images or additional assets.

Gradient

A restrained surface gradient adds dimension without reducing text contrast or overwhelming the component.

Motion

Hover movement is limited to a transform and is disabled when the user requests reduced motion.

REUSE

Component guidance

This pattern works well for feature collections, product previews, service tiers, and editorial cards where each item needs a consistent visual frame.

  1. Keep card content short enough to preserve balanced surfaces.
  2. Use one active state at a time when adding carousel behavior.
  3. Keep controls visible and keyboard reachable.
  4. Use the same spacing scale across every card variation.

CHECKLIST

Before reuse

  • Confirm sufficient contrast between text and the surface.
  • Test the stacked layout on narrow screens.
  • Verify focus visibility with keyboard navigation.
  • Respect reduced-motion preferences.
