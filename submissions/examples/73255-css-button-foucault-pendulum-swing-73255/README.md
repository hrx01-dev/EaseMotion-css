# CSS Button: Foucault Pendulum Swing

Issue #73255 demonstrates a pendulum-inspired button with a suspended decorative marker that swings around a fixed pivot.

## Requirements covered

- Pure HTML and vanilla CSS
- Smooth CSS motion
- Responsive layout
- Transform-based animation
- Native keyboard-accessible buttons
- Reduced-motion fallback

The pendulum is decorative and positioned independently of the button flow. The button remains usable even when motion is disabled.

## Files

- `demo.html` — complete button demonstration
- `style.css` — pendulum geometry, interaction, and responsive rules
- `README.md` — documentation
