# Interactive Input — Dark Mode

## Issue

EaseMotion CSS issue #78790.

## Overview

A responsive dark-mode input form with animated focus feedback and clear labels.

## Features

- Native form controls
- Strong keyboard focus states
- Responsive layout
- Dark visual system
- Reduced-motion support

## Usage

Open `demo.html` and reuse `.field` with native input, select, or textarea controls.

## Accessibility

Labels remain visible, controls use native semantics, focus states are explicit, and decorative transitions stop for reduced-motion users.
