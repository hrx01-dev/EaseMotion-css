# Dynamic Hero Section — Issue #78669

Responsive hero showcase with layered visual depth, clear typography, and a lightweight call-to-action.

## Files

- `demo.html` — semantic hero markup.
- `style.css` — layout, visual treatment, responsive spacing, and motion preferences.

## Usage

Link `style.css` and place the `.hero` markup in the page. Replace the copy and CTA destination with production content.

## Accessibility

The CTA is a native link with keyboard focus support, and reduced-motion preferences are respected.
