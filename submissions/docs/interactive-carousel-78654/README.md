# Interactive Carousel

Documentation for the Interactive Carousel component requested in issue #78654.

## Usage

The demo presents a small set of slides with previous and next controls. Each control updates the visible slide while the surrounding layout remains responsive.

## Files

- `demo.html` — interactive carousel example.
- `style.css` — responsive carousel presentation.

## Accessibility

Controls have accessible labels and the current slide is announced through a status region.

## Customization

Replace the slide content, spacing, transition timing, and navigation styling without changing the basic structure.
