Theme configuration

Use the component tokens to adapt the loader to a different surface or brand accent.

  --surface: #e7ebf2;

Implementation notes

  • Keep the spinner decorative with aria-hidden.
  • Expose meaningful loading text through a live status region.
  • Override custom properties instead of duplicating the component CSS.
  • Respect reduced-motion preferences for users who disable animation.
