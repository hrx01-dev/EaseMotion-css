# Dynamic Navbar

Documentation for the Dynamic Navbar component requested in issue #78662.

## Usage

The example uses a semantic header and navigation that changes presentation as the page scrolls. The small script toggles a compact state while the CSS handles the visual transition.

## Files

- `demo.html` — complete usage example.
- `style.css` — responsive, properly spaced styling.

## Accessibility

Navigation uses semantic elements, visible focus states, and remains usable when the compact state is active.

## Customization

Adjust the header offset, transition duration, navigation spacing, and compact styling in `style.css`.
