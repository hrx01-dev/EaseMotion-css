# Morphing Loader

Documentation for the Morphing Loader component requested in issue #78653.

## Usage

Use the loader while asynchronous content is unavailable. The demo uses a small set of CSS shapes that morph continuously and remains visually centered.

## Files

- `demo.html` — complete loader usage example.
- `style.css` — responsive and cleanly spaced styling.

## Accessibility

The loader is marked as decorative and the surrounding status text communicates that content is loading. Reduced-motion users receive a static presentation.

## Customization

Change the loader size, shape radius, animation duration, and accent treatment in `style.css`.
