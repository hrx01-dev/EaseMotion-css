# Interactive Card

Documentation for the Interactive Card component requested in issue #78684.

## Usage

Use a semantic article for the card content and add a focused interactive target when the card represents an action. The demo shows hover, focus, and keyboard-friendly behavior.

## Files

- `demo.html` — complete usage example.
- `style.css` — responsive, properly spaced styling.

## Accessibility

The primary action is a real link, focus is visible, and the card content remains readable without motion.

## Customization

Adjust card spacing, lift distance, shadow, border treatment, and responsive sizing in `style.css`.
