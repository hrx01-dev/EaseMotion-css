# CSS-only Breadcrumb

Documentation for the CSS-only Breadcrumb component requested in issue #78643.

## Usage

Use an ordered list for navigation hierarchy and style separators with CSS. No JavaScript is required for the visual treatment.

## Files

- `demo.html` — semantic breadcrumb example.
- `style.css` — responsive, properly spaced presentation.

## Accessibility

The navigation uses a labeled `<nav>`, an ordered list, and a current-page marker so the hierarchy remains understandable without visual styling.

## Customization

Change separator symbols, spacing, typography, and active-state treatment in `style.css`.
