# 3D Accordion

Documentation for the 3D Accordion component requested in issue #78659.

## Usage

The demo uses native `<details>` and `<summary>` elements with CSS perspective and layered transforms for depth. This keeps the interaction functional without JavaScript.

## Files

- `demo.html` — complete accordion example.
- `style.css` — responsive 3D presentation with clean spacing.

## Accessibility

Native disclosure semantics provide keyboard support and a clear expanded state.

## Customization

Adjust perspective, rotation, panel depth, spacing, and colors in `style.css`.
