# Animated Breadcrumb

Documentation for the Animated Breadcrumb component requested in issue #78660.

## Usage

Use the same semantic breadcrumb structure as a normal navigation trail and apply animation to the link and separator presentation.

## Files

- `demo.html` — complete usage example.
- `style.css` — responsive, properly spaced styles.

## Accessibility

The navigation has an accessible label, the current location is marked with `aria-current`, and focus states remain visible.

## Customization

Change the reveal distance, transition timing, separator, and active color in `style.css`.
