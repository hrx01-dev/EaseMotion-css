# Floating Footer

Documentation for the Floating Footer component requested in issue #78655.

## Usage

Place a concise navigation group in a fixed footer and keep enough bottom spacing in the page so content is never obscured.

## Files

- `demo.html` — complete usage example.
- `style.css` — responsive, properly spaced styles.

## Accessibility

Navigation remains keyboard reachable and the footer uses a semantic `<footer>` and `<nav>`.

## Customization

Adjust footer width, offset, surface, shadow, and mobile layout in `style.css`.
