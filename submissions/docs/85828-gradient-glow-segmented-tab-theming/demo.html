Gradient Glow Segmented Tabs

A themeable segmented control with explicit active states and CSS custom properties for adapting the visual treatment to a product theme.

Theming scope

Account

Surface, text, border, active, and glow values are exposed on the component. The example keeps the content panel visible so the relationship between the selected tab and its content is clear even in a static documentation demo.

Overview

Use the active segment to communicate the currently selected section.

Activity

Place recent activity content in this panel when the Activity segment is selected.

Settings

Use the final panel for account preferences and other configuration controls.

Theme tokens

Override --tab-surface, --tab-text, --tab-active, --tab-glow, and --tab-border on the tab component to create a new visual theme.
