Brutalism Segmented Switch

A themeable segmented control using native buttons, explicit pressed states, strong borders, and CSS custom properties for brutalist styling.

Theming scope

Display mode

Choose how the example content should be presented. The active segment uses aria-pressed so the selected state is communicated semantically.

Preview

Grid mode keeps related content visible in a structured set of cards.

Theme tokens

  • --switch-border controls the strong component outline.
  • --switch-surface controls the segmented background.
  • --switch-active controls the selected segment.
  • --switch-active-text controls selected text.
  • --switch-shadow controls the offset brutalist depth.
