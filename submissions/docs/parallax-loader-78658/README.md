# Parallax Loader

Documentation for the Parallax Loader component requested in issue #78658.

## Usage

The demo uses layered loading elements with different vertical movement rates to create a restrained parallax effect.

## Files

- `demo.html` — complete usage example.
- `style.css` — responsive, properly spaced styling.

## Accessibility

Loading status is communicated with text while decorative layers are hidden from assistive technology. Reduced-motion users receive a static loader.

## Customization

Change layer count, movement distance, timing, and spacing in `style.css`.
